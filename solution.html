Hướng dẫn giải chi tiết

BÀI: HÀNG CÂY (TREE)
Tóm tắt đề bài
  • Dữ liệu vào: Cho dãy n cây với độ đẹp lần lượt là dãy số a1, a2, ..., an. Cho hai số nguyên số P và w.
  • Yêu cầu: Đếm số lượng đoạn liên tục [l, r] (1 ≤ l ≤ r ≤ n) thỏa mãn đồng thời hai điều kiện:
    • Tổng độ đẹp của đoạn bằng chính xác P: al + al+1 + ... + ar = P.
    • Độ đẹp lớn nhất của một cây trong đoạn không vượt quá w: max(al, al+1, ..., ar) ≤ w.
  • Ràng buộc dữ liệu: 1 ≤ n ≤ 2 × 105; |P| ≤ 1015; |w| ≤ 109; |ai| ≤ 109.
  • Tệp dữ liệu: Đọc từ file TREE.INP, ghi kết quả ra file TREE.OUT.

1. Phân tích bài toán & Nhận xét quan trọng

Điều kiện max(al, al+1, ..., ar) ≤ w mang một tính chất cốt lõi: Tất cả các phần tử nằm trong đoạn từ l đến r đều phải có giá trị nhỏ hơn hoặc bằng w. Nếu tồn tại bất kỳ một cây thứ k nào có độ đẹp lớn hơn w (ak > w), thì cây đó chắc chắn không bao giờ được phép xuất hiện trong bất kỳ đoạn [l, r] hợp lệ nào.

Từ nhận xét này, ta có thể chia nhỏ dãy ban đầu thành các phân đoạn độc lập bằng cách xem các phần tử có ak > w như là các "vách ngăn". Bài toán quy về: Trên từng phân đoạn chứa toàn bộ các cây có độ đẹp ≤ w, tìm số lượng đoạn con liên tục có tổng bằng P.

2. Phương pháp giải chi tiết từng Subtask

Subtask 1 & 2 (30% số điểm): n ≤ 2000

Với giới hạn nhỏ này, ta có thể dùng 2 vòng lặp lồng nhau duyệt qua mọi cặp (l, r). Ta duy trì biến tổng current_sum và giá trị lớn nhất current_max khi mở rộng đầu mút r từ l đến n để kiểm tra điều kiện trong thời gian O(n2).

Subtask 6 (100% số điểm - Trường hợp tổng quát): n ≤ 2 × 105

Để giải quyết trọn vẹn bài toán trong thời gian tối ưu, ta sử dụng kỹ thuật Mảng cộng dồn (Prefix Sum) kết hợp Cấu trúc dữ liệu Ánh xạ (std::map):

  • Ta duyệt qua dãy từ trái sang phải. Khi gặp một cây có ai > w, ta xóa trắng (clear) bảng băm/map tần suất cộng dồn hiện tại để bắt đầu một phân đoạn mới.
  • Với các cây hợp lệ (ai ≤ w), ta tính tổng cộng dồn tích lũy S. Để tìm số lượng vị trí l-1 phía trước thỏa mãn Scurrent − Sl-1 = P ⇔ Sl-1 = Scurrent − P, ta chỉ cần tra cứu số lần xuất hiện của giá trị Scurrent − P đã được lưu trong std::map trước đó.

Độ phức tạp: O(n log n) khi dùng std::map, hoàn toàn tối ưu và ăn trọn vẹn điểm số.

3. Mã nguồn mẫu C++ đầy đủ (Phân tách cấu trúc Subtask)

#include <iostream>
#include <fstream>
#include <vector>
#include <cmath>
#include <algorithm>
#include <map>

using namespace std;

long long a[200005];

// Subtask 1 & 2: Duyệt trâu hai vòng lặp lồng nhau O(n^2)
void sub1_2(int n, long long P, long long w) {
    long long count_valid = 0;
    for (int l = 1; l <= n; ++l) {
        long long current_sum = 0;
        long long current_max = -2e18; // Khởi tạo min cực tiểu
        for (int r = l; r <= n; ++r) {
            current_sum += a[r];
            current_max = max(current_max, a[r]);
            
            if (current_sum == P && current_max <= w) {
                count_valid++;
            }
        }
    }
    cout << count_valid << "\n";
}

// Subtask tối ưu: Map + Mảng cộng dồn chia nhỏ phân đoạn O(n log n)
void sub_full(int n, long long P, long long w) {
    long long count_valid = 0;
    map<long long, int> prefix_counts;
    
    // Khởi tạo trạng thái rỗng cho phân đoạn đầu tiên
    prefix_counts[0] = 1;
    long long current_prefix_sum = 0;
    
    for (int i = 1; i <= n; ++i) {
        if (a[i] > w) {
            // Gặp phần tử vi phạm -> Đóng phân đoạn cũ, làm sạch map để mở phân đoạn mới
            prefix_counts.clear();
            prefix_counts[0] = 1;
            current_prefix_sum = 0;
        } else {
            current_prefix_sum += a[i];
            long long target = current_prefix_sum - P;
            
            if (prefix_counts.count(target)) {
                count_valid += prefix_counts[target];
            }
            
            prefix_counts[current_prefix_sum]++;
        }
    }
    cout << count_valid << "\n";
}

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(NULL);

    if (ifstream("TREE.INP")) {
        freopen("TREE.INP", "r", stdin);
        freopen("TREE.OUT", "w", stdout);
    }

    int n;
    long long P, w;
    cin >> n >> P >> w;

    for (int i = 1; i <= n; ++i) {
        cin >> a[i];
    }

    // Cơ chế rẽ nhánh subtask rõ ràng theo cấu trúc phân tách bài làm
    if (n <= 2000) {
        sub1_2(n, P, w);
    } else {
        sub_full(n, P, w);
    }

    return 0;
}
